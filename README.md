# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.
# zegocloud-video-call-app
📞 Build a Video Calling App Using ZEGOCLOUD UIKits (React JS)

This project demonstrates how to create a full-featured video call application using ZEGOCLOUD UIKits in React JS with minimal code. Ideal for developers looking to quickly integrate real-time audio/video calling into their apps using a low-code solution.

🚀 Features:
Real-time video and audio call functionality

UI components like call buttons, mute, camera toggle, and screen sharing

Cross-platform support (Web, Android, iOS, Flutter)

Free 10,000 minutes for testing

Simple React integration with App ID and App Sign configuration
